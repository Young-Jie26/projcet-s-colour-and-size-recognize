# 颜色块检测 + 40mm 见方判定（MaixCAM / MaixCAM2）

检测画面里的彩色方块，并把**像素尺寸换算成毫米**，只把尺寸落在 **40mm 见方**以内的色块标为合格。

## 两步走

### 第 1 步：标定（只需做一次）

1. 打开 `1_calibrate_mm.py`，改两个地方：
   - `KNOWN_MM`：标定物的真实边长，用 40mm 方块就填 `40`
   - `COLOR_TH`：这个方块的颜色阈值（LAB）
2. 把方块正对镜头、**边与画面横竖平行**（别斜放），保持你以后实际使用的工作距离。
3. 运行，终端出现下面两行就成功了，结果存在 `/root/blob_calib.json`：

```
[OK] 标定完成: 目标平均像素 = 87.0 px
[OK] 结果: 0.4598 mm/px，已保存到 /root/blob_calib.json
```

> 原理：`mm/px = 已知边长(mm) / 该边长占的像素数`。所以标定必须在**实际工作距离**上做。

### 第 2 步：检测

直接运行 `2_find_blocks.py`：

```
[frame    42] blobs=3 pass=1 red 40mm @(144,123) d=(-7,+1)mm
```

- `blobs`：所有颜色加起来检出多少个
- `pass`：其中尺寸合格的有几个
- `d=(dx,dy)`：相对画面中心的偏移（mm），做机械臂/舵机对准时可直接用

屏幕上：合格块标绿字，不合格标白字并带 `x` 后缀。

## 参数说明（`2_find_blocks.py` 顶部）

| 参数 | 默认 | 说明 |
|---|---|---|
| `CAM_W, CAM_H` | 320, 240 | 必须和标定时一致（换分辨率会自动等比换算） |
| `COLORS` | 红/绿/蓝/黄 | `(名字, LAB阈值, 画框颜色)`，可增删 |
| `MIN_PIXELS` | 120 | 小于这个像素数当噪点丢弃 |
| `SIZE_MAX_MM` | 40.0 | 尺寸上限 |
| `SIZE_TOL` | 1.10 | 允许 10% 误差（40mm 判到 44mm 也算过） |
| `SIZE_MIN_MM` | 8.0 | 太小也不看 |
| `REQUIRE_SQUARE` | True | 是否要求形状接近正方形 |
| `SQUARE_MIN/MAX` | 0.65 / 1.55 | 外接框宽高比范围；方块斜放 45° 时约 1.41，所以上限放宽到 1.55 |

## 为什么用 `sqrt(w*h)` 而不是外接框

色块**斜放**时，外接矩形会比真实边长大约 1.41 倍（45° 时），直接用宽或高判断会误杀。
所以用几何平均 `side = sqrt(w_mm * h_mm)`，对旋转不敏感，再用宽高比做一次“是不是方形”的检查。

## 颜色阈值怎么调

**推荐**：用设备自带的「找色块」App，界面里点一下色块就能看到 LAB 值，并实时看阈值效果，调好后把三组数字抄进 `COLORS`。

阈值格式：

```python
[Lmin, Lmax, Amin, Amax, Bmin, Bmax]
```

可以写多段，例如把红色分成两段（红在 LAB 色环上跨 0）：

```python
("red", [[0, 80, 40, 80, 10, 80], [0, 80, 60, 90, -20, 20]], image.COLOR_RED),
```

经验值：L 控制明暗（0 黑 ~ 100 白），A 正红负绿，B 正黄负蓝。

## 距离变了怎么办

`mm/px` 与距离**成正比**：距离翻倍，同一个色块测出来的 mm 也翻倍。
如果实际工作时距离会变，有两个办法：

1. 每个工作距离各标定一次；
2. 用测距（超声波/ToF/已知工位）做在线补偿：`mm_per_px_now = mm_per_px_calib * (dist_now / dist_calib)`。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| pass 一直是 0 | 没标定 / 尺寸超限 | 看 HUD 是 `NO CALIB` 还是数值超了 44mm |
| 同一个块被分成好几个 | 光照不均、阈值太窄 | 加 `merge`（部分固件支持）或调宽阈值、加 `MIN_PIXELS` |
| 白色/灰色也被检出 | LAB 阈值范围太宽 | 收紧 A/B 范围，或加亮度约束 |
| 反光导致中间有洞 | 镜面反射 | 换漫反射光源/柔光，或把面积阈值调小 |
| 换分辨率后尺寸不对 | 标定分辨率不同 | 脚本会自动按宽度等比换算；但最好在同一分辨率下标定 |
